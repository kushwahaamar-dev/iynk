## 1. Summary

Register of 119 claims:

| Status | Claims |
|---|---|
| VERIFIED | 37 |
| VERIFIED-PARTIAL | 55 |
| DOCUMENTED only | 6 |
| CONTRADICTED | 8 |
| UNKNOWN | 13 |

What the numbers say, in order of weight:

1. **The headline counts are correct.** Items, lessons, tasks, failures, faults, steps, tests, courses, snippets, languages and golden rows all match the code (section 2). Two are worded loosely: "272 steps" is robotics only (579 across all labs), and "80 figures" includes 42 part, module and range pages.
2. **The simulators are real code but smaller than the copy suggests.** The C++, Python and Verilog interpreters are from-scratch subsets, not emulators. The circuit solver is DC only and serves breadboard circuits. The flight model is an arcade point mass. Faults are scripted.
3. **Eight claims are contradicted.** The two that matter most: "the server re-runs your exact run" before a credential is issued (a seven-event hand-written log gets a perfect score and anyone can mint to any wallet), and "priced live" (the SerpApi key had 0 of 250 searches left and returned HTTP 429 on 2026-10-26). The others are wording slips: "80 figures" for 38 items, "every course" has medals, "445 calculator tests", the "[342]" placeholder, "all sponsors live", and the Solana UI text that repeats the re-run claim.
4. **Verification is client-side everywhere.** Lesson checks, lap times and credential logs are computed or supplied by the browser. There is no server-side check that a learner did the thing.
5. **Nothing a learner makes is saved or shared by account.** There are no accounts, no projects, no server-side save. Edited code is lost on reload.
6. **The test suite is large but mostly proves self-consistency.** It passes 2,786 of 2,802 on a heavily loaded laptop and 102 of 102 lesson references in isolation; three figure-driven cases (basys3 chip sweep, octo landing gear, wing elevon) still time out when re-run alone under load. It compares the project to itself and to a third-party calculator, not to hardware.
7. **Provenance and licence are unresolved.** No LICENSE, drone constants and lesson structure follow three third-party sites, and git cannot show when the code was written.
