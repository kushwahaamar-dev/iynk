# Competitive matrix (BRIEF 5.3)

Written 2026-10-27. 27 dimensions, 23 rows (iynk plus 22 competitors), four tables. Built only from the fact-checked dossiers, the workflow benchmark and iynk's own audit files. No new web research was done for this file. Nothing outside `docs/MASTER_PLAN/` was touched.

This version replaces an earlier draft with 12 grouped columns. The brief now asks for one row per product and the dimensions as columns, so the file was rebuilt. A copy of the old draft is in `/Users/amar/iynk-master-plan-scratch/research/competitor-matrix/`.

## 1. How to read this file

**Layout.** Each of the four tables has iynk as the first row. Dimensions are the columns. The 27 dimensions of BRIEF 5.3 are split as follows.

| Table | Dimensions (count) |
|---|---|
| 1. Access and price | free usage; no-account entry; browser compatibility; pricing; performance; target audience (6) |
| 2. Building and simulation | user-created projects; circuit editor; custom hardware models; firmware compatibility; MCU simulation fidelity; analog circuit fidelity; failure modeling; debugging tools; robotics simulation; drone simulation (10) |
| 3. Learning, AI and collaboration | AI guidance; multilingual accessibility; real-time collaboration; curriculum integration; community features (5) |
| 4. Physical build, extensibility and moat | physical BOM generation; real component purchasing; export to real toolchains; plugin extensibility; strength of ecosystem; competitive moat (6) |

**Each cell** is a short value, then one or more labels in brackets-and-parentheses form: `(LABEL [source])`. A cell with two labels keeps two kinds of evidence apart.

**iynk labels** (cells for iynk come only from `01_AUDIT/FEATURE_VERIFICATION.md` and `01_AUDIT/runs/BROWSER_WALK.md`):

| Label | Meaning |
|---|---|
| VERIFIED | Shown by a run or by reading the code, as recorded in those two files. The value says which part and what was not covered. |
| DOCUMENTED | Only marketing copy or a project document says it. Nobody in the audit ran it. |
| CONTRADICTED | A run or reproduction shows the claim is wrong as worded. |
| UNKNOWN | Neither file states it. |

An absence (for example "no export") is VERIFIED only where the audit tried and failed to do the thing. Where an iynk cell needs a fact that only the workflow benchmark records, the cell says so in words and does not label it VERIFIED.

**Competitor labels.**

| Label | Meaning |
|---|---|
| TESTED | Someone on this project ran it and wrote down the result (`WORKFLOW_BENCHMARK.md`, plus GitHub API counts and local timing runs in the dossiers). Only Wokwi, Falstad, MakeCode and Velxio have hands-on web evidence, and only for the tasks the benchmark covered. |
| EXTERNAL | A source that is not the vendor's own sales copy states it: docs, repository pages, forums, trade press, Wikipedia, a store page. |
| CLAIM | The vendor's own marketing, or a self-reported figure (user counts, speed, fidelity, "real physics"). Kept apart because nobody checked it. |
| HYPOTHESIS, ESTIMATED | The dossier's own labels, kept. Moat cells are HYPOTHESIS by nature. |
| UNKNOWN | No source read states it. This is not "no". |

**Source tags.** The dossier name, then its own reference: `[embedded-sim S1]`. Other tags: `FV` is `01_AUDIT/FEATURE_VERIFICATION.md` (claim ids such as C002, "sec" is a section number). `walk` is `01_AUDIT/runs/BROWSER_WALK.md`. `workflow-benchmark` is `WORKFLOW_BENCHMARK.md` ("S" numbers there are its own source table). `simulation-options` and `market-analysis` are the tech and market files. `circuit-eda`, `education`, `robotics`, `drone`, `ecosystems`, `ai-hardware`, `embedded-sim` are the competitor dossiers. "table" after a dossier name means its comparison table.

All prices are as the dossiers recorded them on 2026-10-26.

**Limits that apply to every cell.**

- The four tested competitor columns were driven by a script in headless Chromium on one Mac. Wiring by mouse was not tested for Wokwi, Falstad or Velxio. No human used any of them. Tinkercad, Proteus and Arduino Cloud were not tested (account or install needed).
- Competitor numbers are vendor figures unless the cell says TESTED.
- UNKNOWN in a competitor cell means the dossiers did not find it. Several dossier "No" answers are "not found in the pages read".
- iynk was walked in Chromium and in the WebKit 26.0 engine (macOS build, with desktop and iPhone 14 viewports). Firefox and real iOS Safari were not run.
